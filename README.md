# Bajo fácil · No te pido flores (Eb)

App web para aprender en bajo eléctrico de 4 cuerdas la canción completa *No te pido flores*, pensada para principiantes.

- 8 pasos guiados: conocer las notas, coro, estrofa, pre-coro, intro, puente y canción completa
- Qué tocar en lenguaje simple (cuerda y traste), diapasón animado y tablatura
- Bajo guía, metrónomo, cuenta regresiva y tempo ajustable
- Funciona en celular y computador

Especificaciones: **Eb · 106 BPM · A = 440 Hz**.

**Tocar con la grabación:** en cada paso puedes cargar el MP3 desde tu equipo. La app lo reproduce sincronizado con los acordes, con tempo ajustable sin cambiar el tono. El archivo se guarda solo en tu navegador; no está en este repositorio.

Estructura de acordes tomada del PDF "No Te Pido Flores Cover Bass Miguel Torres" (acordes generados con Moises.ai). La duración de cada acorde se alineó automáticamente con la grabación; puede haber pequeños desfases.
